Recall · CORE 203 · PROD 401 · APP 305

SFT / preference stages (CORE 203) capability substrate ke baad behavior shape karte hain. RAG facts ko weights mein bake kiye bina update karti hai (APP 305). PROD 401 regression gate ke bina FT candidate ship mat karo.

1. FT vs RAG vs prompting — decide with numbers

Teen levers, alag jobs:

  • Prompting — cheapest; style/format/tool policy; weak when knowledge missing.
  • RAG — churning facts, citations, tenant docs; weak when behavior/style must change deeply.
  • Fine-tune (PEFT) — stable domain format, tone, tool habits; dangerous when eval leaks or facts churn.

Lab recommend_adaptation(evidence) teaching policy: leakage / forgetting / demo–golden gap / knowledge refresh pe fine-tune ineligible; warna best eligible score with cost-first tie-break.

2. Data leakage into eval — silent false wins

Agar FT train tickets aur golden items overlapping dumps se aaye, ft_score “magic” dikhega. Yeh capability nahi — contamination hai. Habit: train/eval provenance document karo; near-duplicate dedupe; leakage flag on hone pe FT refuse (eval_leakage_risk in the lab).

Pitfall · demo better, golden worse

Vendor demo slice pe LoRA 0.81, held-out golden 0.64 — classic trap. Lab compare_demo_vs_golden / decision flag gap ≥ 0.15 pe FT block karti hai. Ship signal = golden (+ regression vs baseline), demo nahi.

3. Catastrophic forgetting — intuition

Adaptation preferred behaviors boost karti hai; purane golden behaviors softly decay kar sakte hain (lab ka toy_preference_update yahi cartoon hai). Measure: before/after on held-out golden, not only the FT task. finetune_metric_comparison forgetting tab true karti hai jab golden_delta < 0.

4. LoRA / QLoRA — PEFT intuition (no cluster required)

Full fine-tune har weight move karti hai — storage + multi-tenant hosting expensive. LoRA (Hu et al.) pretrained W freeze karke low-rank update ΔW = scale · (B A) seekhti hai: A is (r × in), B is (out × r). Trainable params ≈ r·(in+out) instead of in·out. QLoRA intuition: base weights quantized (4-bit class recipes) + LoRA adapters trainable — memory down, recipe complexity up. Course lab huge models download nahi karti; NumPy se apply_lora math.

Self-check · formative only

1. Kab FT ko pehle refuse karoge even if ft_score high ho?

Reveal answer

Eval leakage risk, catastrophic forgetting delta above threshold, demo≫golden gap, ya knowledge churn that RAG should own.

2. LoRA mein trainable matrices kaunsi?

Reveal answer

Low-rank A aur B; base W frozen. Update W + scale·(B A).

3. “Demo better, golden worse” ship signal kya hai?

Reveal answer

Do not ship on demo. Golden (+ regression vs baseline) decide karti hai; investigate slice mismatch / leakage.
