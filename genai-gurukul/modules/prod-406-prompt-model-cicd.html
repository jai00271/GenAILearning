1. Regression-eval gates in CI

Har prompt/model PR pe: frozen baseline metrics vs candidate; max_drop fail-closed. Quality metrics (judge agree, task F1) higher-is-better. Trace metrics (tool_error_rate, p95_latency_ms) lower-is-better — max_trace_worsen. Lab ci_eval_gate dono; CI annotation string logs mein chipkao.

2. Canary for prompt changes

CI green ke baad bhi seedha 100% risky hai. Staged canary: 1% → 5% → 25% → 100% (lab canary_plan). Har stage pe watch: error rate, cost/tenant, injection flags (403), TTFT/total (405). Flat eval + worse traces → halt canary, rollback artifact.

3. Feature-flagged model swaps (LaunchDarkly parallel)

Model id / prompt version ko flag treatment banao. Percentage rollout + sticky key (user/tenant hash) taaki same user thrash na kare control ↔ treatment. Lab sticky_bucket / in_rollout / choose_variant — teaching API, LaunchDarkly SDK nahi. Production mein LD (ya equivalent) percentage rollouts + experiments same idea.

Source · LaunchDarkly percentage rollouts

LaunchDarkly documents percentage rollouts and consistent bucketing so the same context stays in the same cohort as the percentage expands — see docs.launchdarkly.com/home/flags/rollouts (verify current UI terms). Lab hashes are didactic stand-ins.

4. Prompt versioning, artifacts, rollback

Store prompt text + metadata as versioned artifacts (semver / content hash): model id, temperature, tool allowlist fingerprint, eval baseline id. Deploy references immutable artifact ids — not “whatever is in main”. Rollback = point flag control at previous artifact + invalidate caches keyed by prompt/model (404 §5). Jab golden eval flat ho lekin Datadog traces (tool errors, retries, cost) worsen — rollback even if CI quality slice looked fine; next time gate mein trace metrics add karo.

Pitfall

Prompt ko Notion comment samajhna. Bina artifact id / flag / gate ke “quick edit” production drift hai. Doosra: random bucketing without sticky keys — users flicker.

Portfolio-facing English · Decision stub

Gate every prompt and model candidate in CI on frozen offline metrics and on trace worsen signals. Ship through sticky percentage canaries, not big-bang cutovers. Version prompts as immutable artifacts; roll back by repointing the flag when eval looks flat but production traces degrade — then tighten the gate.
