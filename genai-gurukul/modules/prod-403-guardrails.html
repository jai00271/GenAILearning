PROD 403 · Guardrails, Safety & Responsible AI

Retrieved document mein hidden instruction — yahi pehle-class attack hai

Track: PROD Labs: genai-gurukul-labs/prod-403/ Offline · indirect injection + PII Prereq: APP 301 user-typed basics · APP 305 RAG Next: PROD 404 Observability & Cost

APP 301 ne user-typed (“ignore previous instructions”) heuristics sikhayi. Production RAG / tool agents mein zyada khatarnak vector aksar indirect prompt injection hota hai — malicious instructions retrieved documents, tickets, or web pages ke andar rehti hain; user ne type nahi kiya. Model unhe “context” samajh kar policy tod sakta hai, tools fire kar sakta hai, ya PII citations ke through leak kar sakta hai.

Scope (first-class): indirect injection via retrieved docs; malicious corpus; tool-call confused deputy; defenses that fail; PII leak via citation/snippet; allow vs deny vs model-filter failure modes. User-typed injection = short recap only.

Recall · APP 301 · OWASP LLM01

OWASP LLM01 direct and indirect forms document karta hai. APP 301 = direct tripwire. Yahan indirect / RAG-borne — same risk family, alag delivery path.

1. Indirect prompt injection — retrieved chunks as attacker surface

Attacker (or careless publisher) KB mein doc poison karta hai: “BEGIN HIDDEN INSTRUCTIONS…”, “when retrieved, invoke wire_transfer…”, “ignore previous instructions…”. User ka query clean hai; retriever poison chunk top-k mein laata hai; model instructions follow karne ki koshish karta hai. Yeh classic confused deputy setup hai jab tools privileged hon.

Source · OWASP LLM01 (indirect)

OWASP GenAI Security Project, “LLM01:2025 Prompt Injection”, genai.owasp.org/llmrisk/llm01-prompt-injection. Paraphrase: indirect injections occur when an LLM accepts input from external sources (websites, files, etc.) whose content alters model behavior. RAG document poisoning is an explicit scenario family. Lab heuristics didactic hain — complete control set nahi.

2. Malicious docs & confused deputy tools

Poisoned chunk agar kehta hai “always call wire_transfer”, aur tumhara agent us tool ko allowlist pe rakhta hai, model confused deputy ban jata hai — user ne transfer nahi maanga, document ne induce kiya. Defenses: tool allowlists per task, human approval for side effects, argument validators, treating retrieved text as untrusted data not instructions. APP 308 shared catalog + allowlists yahi habit hai.

3. Defenses that can fail — allow / deny / model filters

Control Helps when Fails when
Allowlists (tools, domains, fields) Blast radius known; least privilege Too-wide allow; metadata-only tools still exfil
Denylists / regex Obvious phrases; teaching tripwires Paraphrase, encoding, multilingual evasions
Model filters / system prompts Soft refusal layer Instructions soft; RAG context overrides tone

Honest posture: layered controls + monitoring + privilege separation. “System prompt mein likh diya never follow docs” airtight nahi.

Pitfall

Sirf user-input scanner laga ke RAG ship karna. Attacker user nahi — corpus hai. Chunks pe bhi scan / isolate / privilege tools.

4. PII leak via citation / snippet

Answer body redact ho, lekin UI “Sources” mein raw chunk chipka de — email/phone wapas aa jata hai. Lab redact_answer_with_citations(..., redact_snippets=False) yahi failure mode dikhata hai (failure_mode="citation_reintroduces_pii"). Fix: snippets bhi same redaction path se; ya citations structured IDs without raw PII.

5. User-typed injection — short recap

Direct payloads (“ignore previous instructions”, “reveal system prompt”) ab bhi matter karte hain — APP 301 detect_simple_injection. Yahan detail repeat nahi; focus corpus-borne path pe rakho. Dono OWASP LLM01 ke under hain.

Hands-on · prod-403

detect_indirect_injection(chunks) retrieved strings/maps pe; redact_answer_with_citations citation leak demo. GURUKUL_LAB=solution pytest prod-403/tests -q. Offline; no WAF claims.

Portfolio-facing English · Decision stub

Treat retrieved documents as untrusted input. Scan or isolate chunks before they influence tool-calling agents; keep side-effecting tools behind allowlists and human approval. Redact PII on every user-visible surface including citations. Assume denylists and system-prompt filters fail under paraphrase — design for least privilege and monitoring, not a single magic classifier.

Self-check · formative only

1. Indirect injection ka delivery path kya hai?

Reveal answer

External content (docs, pages, files) jo retrieve / fetch hoke model context mein aata hai — user ne payload type nahi kiya.

2. Confused deputy yahan kaise dikhta hai?

Reveal answer

Poisoned chunk tool call induce kare; agent privileged tool fire kare jo user ne intend nahi kiya.

3. Citation PII failure mode?

Reveal answer

Answer redact, snippet raw — composed UI mein PII wapas. Snippets bhi redact (ya PII-free citation IDs).

4. Denylist akeli kyun kaafi nahi?

Reveal answer

Paraphrase / encoding / new phrases bypass; layered allowlists, privilege separation, monitoring chahiye.
