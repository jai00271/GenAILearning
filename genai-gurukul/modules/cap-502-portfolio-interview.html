Recall · CAP 501 acceptance

Golden ≥40 · Recall@5 ≥ 0.60 · TTFT + total p95 · cost model · auth/trace/rate-limit/failover · failure modes (indirect injection + cost blowup). Interviewer ko yahi “production GenAI” signal hai — Lambda demo nahi.

1. Portfolio kaise dikhao (3-minute spine)

  1. Problem — on-call noise; runbooks scattered; unsafe next steps.
  2. System — multi-format RAG + optional agent; prod edge controls.
  3. Proof — Recall@5, latency p95, $/1k queries, two failure modes.
  4. Judgment — what you postponed (multi-agent crew, auto-remediation) and when you reverse.

Detail: English one-pager interview/presenting-capstone.md — eval + cost + failure modes order fixed rakho. Diagram baad mein; metrics pehle.

2. GenAI system-design questions (roles)

Practice bank English file: interview/system-design-onepager.md aur interview/genai-interview-bank.md. Sample themes:

  • RAG vs fine-tune for ops runbooks — when each wins.
  • Where to put auth, rate limits, and tenancy for an internal copilot.
  • How you evaluate retrieval vs generation vs agent trajectories.
  • Indirect injection in retrieved tickets — defenses and residual risk.
  • Cost controls for tool-calling loops (caps, caching, model routing).
  • Failover: degraded answer vs hard error; what you log.
Hands-on · drill

Ek mock: 10 minute CAP 501 walkthrough using only writeups/eval_report.md, cost_model.md, failure_modes.md. Agar bina unke architecture pe jump karo, CAP 502 incomplete.

3. Red flags interviewers catch instantly

  • “We put docs on Lambda / Bedrock KB” with no eval protocol.
  • Recall claimed without labeled golden or without stating k.
  • Agent demos with unbounded steps and no $/query story.
  • Safety = “we told the model to be careful” only.
  • Cannot name one residual risk after mitigations.
