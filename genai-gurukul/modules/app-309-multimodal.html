1. Three lanes — image-gen, VLM, audio

“Multimodal” ek bucket nahi — teen alag product shapes hain. Confusion tab aati hai jab aap image generate karne wale model ko image understand karne wale VLM se mix kar do, ya ASR transcript ko “agent memory” samajh lo bina eval ke.

Lane Typical job Watch-outs
Diffusion / image-gen Text → pixels (or img2img / inpaint) Steps × resolution = cost; prompt injection via uploaded refs; brand safety
VLM (vision-language) Image (+ text) → text: caption, QA, UI describe Hallucinated OCR; resolution limits; PII in screenshots
Audio (ASR / TTS) Speech → text, text → speech Accents / noise; streaming latency; consent & retention

2. Diffusion intuition — noise se image, steps se bill

Modern text-to-image mostly latent diffusion: model noise se start karke denoising steps mein structure laata hai (U-Net / DiT family — names perishable). Teaching heuristic lab mein: diffusion_work_units = width × height × steps. Yeh FID nahi hai; yeh relative cost gut-check hai — 1024² × 50 steps 256² × 20 se visibly mehnga feel hona chahiye.

  • Prompt: subject + style + constraints; negative prompts vendor-specific.
  • Seed: reproducibility ke liye; lab seed_from_prompt deterministic 31-bit seed banata hai.
  • Safety: brand / NSFW / likeness filters product feature hain, afterthought nahi.
Intuition · FakeImageClient

Production mein aap SDXL / Flux / DALL·E / Imagen call karoge. Gurukul CI mein GPU nahi chahiye — FakeImageClient seed se solid RGB PNG banata hai, deterministic. Contract same: ImageArtifact(prompt, width, height, mime, data, seed, provider, steps). Optional OllamaImageClient httpx se /api/generate shape seekhata hai (MockTransport in tests); StubOpenAIImageClient paid path ka label hai bina API key ke.

3. VLMs — dekhna ≠ generate karna

Vision-language models image tokens (patches / tiles) ko text tokens ke saath joint space mein laate hain. Use cases: document QA, UI bug describe, shelf / receipt OCR assist. Failure mode classic: model confidently galat digit padh le — isliye grounded eval (golden screenshots + expected fields) text RAG jaisa zaroori hai.

  • Input budget: megapixel limits; resize pehle, blind 4K dump mat.
  • Tooling: VLM aksar agent tool ban'ta hai (“describe_screenshot”) — APP 307 allowlists apply.
  • Privacy: customer PII screenshots third-party VLM pe bhejne se pehle policy.

4. Audio — ASR / TTS survey

ASR (speech-to-text): Whisper-class / cloud speech APIs — batch vs streaming. TTS: product voice, IVR, accessibility. Multimodal “agent that listens” usually ASR → text LLM → (optional) TTS; audio tokens seedha LLM mein ab experimental / vendor-specific hain — survey pehle text bridge assume karo.

  • Measure WER / intent accuracy on your accents, not demo reels.
  • Streaming partial transcripts = UX win + race conditions; version the contract.
  • Retention: call audio often regulated — delete / redact policy PROD track pe deep dive.

5. Portfolio-facing English — when to reach for multimodal

Portfolio-facing English · Decision stub

Reach for multimodal only when the job genuinely needs pixels or audio — not as a demo garnish on a text workflow that already works. Separate image generation from vision-language understanding, put each behind a thin client, and define an eval slice (golden prompts/screenshots/clips) before optimizing model brand names. Treat resolution, steps, and streaming as cost dials with explicit budgets.

2. Diffusion vs VLM — one-line farq?

Reveal answer

Diffusion / image-gen: text (ya image) → new pixels. VLM: image (+ text) → text understanding. Generate ≠ see.

3. Lab diffusion_work_units kya measure karta hai?

Reveal answer

Teaching heuristic: width × height × steps — relative compute/cost gut-check, perceptual quality score nahi.

4. FakeImageClient kyun?

Reveal answer

Offline deterministic PNG — CI mein GPU/API keys ke bina ImageClient contract green. Real providers baad mein swap.

5. Audio multimodal agent ka common bridge?

Reveal answer

ASR → text LLM (+ tools) → optional TTS. Native audio-token LLMs survey-level awareness; default product design abhi text bridge se start.
