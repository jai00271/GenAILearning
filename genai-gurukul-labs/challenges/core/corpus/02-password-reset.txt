Title: Password reset runbook (customer identity)
Channel: #identity-oncall

When a user cannot complete password reset:
1. Confirm the email belongs to an active account in ServiceNow CI
2. Check SES bounce/complaint metrics for the reset template
3. Verify the reset token TTL (default 30 minutes) and clock skew on auth nodes
4. If tokens validate but UI fails, inspect the edge CDN cache for /reset-password

Escalation: page identity-secondary if more than 20 open INC tickets mention reset in 15 minutes.
Never share raw reset tokens in Slack.
